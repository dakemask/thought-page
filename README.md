我是个有想法就想立刻记录的人。如果不记下来，总是担忧自己一时的好想法未来会忘记。除此之外，我也有些待办需要记下来。

过去我总是把这些东西记在很多地方，课本上、手上、笔记本上、手机日历上、笔记软件上。

在ai时代，本着只要自己的需求和现有的轮子有一丁点不一样就自己造轮子的思想。我让ai开发了这个项目，用来按我自己的需求定制记录的形式，以及将以往会分散到各处的记录都集中在一个网页里。

项目可通过 https://dakemask.github.io/my-dashboard/ 直接访问。

项目可以跨设备保留数据。受限于我的财力和知识，数据使用GitHub私人仓库进行存储。如需使用该功能，需要创建一个名为my-dashboard-data的仓库，然后申请一个可以读写仓库内容的token。在项目网页中填写你的GitHub用户名和token（信息保存在浏览器本地），即可使用该仓库存储你的数据。

项目正在缓慢开发，功能可能不稳定。
